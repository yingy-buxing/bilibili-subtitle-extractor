# 安装与使用指南

## 一、安装插件

### 下载

进入 [最新Release](https://github.com/yingy-buxing/bilibili-subtitle-extractor/releases/latest)，下载 Assets 中的 `bilibili-subtitle-extractor-v1.1.0.zip`。

macOS可双击ZIP解压；Windows可右键选择“全部提取”。建议把解压后的文件夹放在文稿或专门的工具目录中，而不是临时下载目录。

你也可以下载GitHub源码ZIP或克隆仓库。无论哪种方式，最终加载的都是包含 `manifest.json` 的 `extension` 文件夹。

### 加载

1. 在Chrome地址栏输入 `chrome://extensions/`，按回车。
2. 打开右上角“开发者模式”。
3. 点击左上角“加载已解压的扩展程序”或“加载未打包的扩展程序”。
4. 在文件选择窗口中进入下载并解压的项目，选中 `extension` 文件夹。
5. 点击“选择文件夹”或“选择”。
6. 页面出现“B站字幕提取（本地）”卡片后，即完成加载。

**选文件夹，不要选择ZIP、`manifest.json` 单个文件或项目最外层目录。**

### 固定图标

点击Chrome右上角的拼图图标，找到“B站字幕提取（本地）”，点击旁边图钉。之后直接点击工具栏上的图标即可打开插件。

## 二、提取字幕

1. 在同一个Chrome中打开B站视频页。插件不会另外打开登录页面；账号登录状态由B站自身管理。
2. 对于分P视频，先切换到需要的分P。当前链接应有对应的 `p` 参数，例如 `?p=2`。
3. 点插件图标，点击“提取当前视频字幕”。
4. 等待出现视频标题、字幕语言、条数和文本预览。**提取期间保持弹窗打开。**
5. 选择需要的字幕语言。多个轨道时可以逐个选择和下载。
6. 按需修改文件名，点击下载按钮。

不需要完整播放视频。通常可直接读取字幕；没有返回时，先在播放器的“翻译和字幕”中开启中文，再提取。

### 选择输出格式

| 格式 | 适合用途 | 文件内容 |
| --- | --- | --- |
| TXT | 阅读、笔记、给AI整理参考资料 | 每条字幕一行，不含时间码 |
| SRT | 剪辑或播放器字幕 | 序号、开始与结束时间、字幕文字 |
| JSON | 进一步开发或数据处理 | `body` 数组，其中含 `from`、`to`、`content` |

时间单位：JSON中的 `from`、`to` 为秒；SRT时间显示为 `时:分:秒,毫秒`。插件保留B站原文，不自动修正识别错误。

### 下载位置

使用Chrome默认下载位置。可在Chrome下载记录中查看文件；macOS按 `⌘⇧J`，Windows按 `Ctrl+J`。

如果没有找到文件，检查浏览器是否弹出了保存位置对话框或下载提示。点击按钮后界面的“已请求下载”提示只表示已触发下载，最终状态以Chrome下载记录为准。

## 三、备用方式：开发者工具面板

如果主流程没有返回字幕，但播放器已经能显示平台字幕，可以尝试保留的网络捕获面板。正常使用不必进入这里。

1. 在B站视频页打开开发者工具：macOS按 `⌘⌥I`，Windows按 `F12` 或 `Ctrl+Shift+I`。
2. 在顶部标签或 `»` 更多标签中选择 **B站字幕提取**。如果插件是打开开发者工具之后才加载的，先关闭并重新打开开发者工具。
3. 保持开发者工具打开，刷新视频页面，再在播放器“翻译和字幕”中选择中文或需要的语言。
4. 面板会尝试读取已存在及新完成的字幕请求。成功时会显示轨道、条数、时间范围和预览。
5. 点击保存TXT、SRT或JSON。

切换视频前先点击“清空轨道”，再加载新视频字幕，避免把上一视频的轨道当成当前视频结果。

### 导入HAR或字幕JSON

备用面板也支持拖放或选择HAR、字幕JSON文件。对于HAR：

1. 在开发者工具的 Network 中筛选 `ai_subtitle`；旧字幕可尝试 `subtitle`。
2. 先确认播放器确实加载了字幕正文请求。
3. 使用Chrome的导出HAR功能，保存包含响应正文的文件。
4. 在面板中导入该HAR。

仅有字幕列表元数据、请求失败、响应正文缺失时，HAR不能提供完整文本。文件在本地解析，导出JSON不会复制HAR中的请求头、Cookie或其他请求记录。包含个人信息的HAR不要发到公开Issue。

## 四、更新与卸载

### 更新

1. 下载新版本并解压。
2. 如果覆盖了原来已加载的 `extension` 文件夹，进入 `chrome://extensions/`，点击插件卡片上的刷新按钮。
3. 刷新B站视频页，再打开插件。
4. 如果新版本放在不同目录，移除旧扩展后，加载新目录中的 `extension` 文件夹。

### 卸载

进入 `chrome://extensions/`，点击插件卡片上的“移除”。已下载到磁盘的字幕文件不会随插件卸载删除。
