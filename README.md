# B站字幕提取

在已登录的哔哩哔哩视频页点击 Chrome 插件，直接提取平台已有字幕，下载为 **TXT、SRT 或 JSON**。

适合整理课程笔记、阅读长视频内容、辅助研究和剪辑。无需完整播放视频，无需复制 Cookie，无需另行扫码登录，也无需安装音频识别模型。

> 这个工具读取B站已经提供的字幕，不会把视频音频重新转写。视频没有可用字幕，或平台接口没有返回字幕时，工具会说明原因。

## 快速开始

**安装一次：** 下载并解压插件 → Chrome加载 `extension` 文件夹。

**每次使用：** 打开B站视频 → 点击插件 → “提取当前视频字幕” → 选择语言 → 下载TXT或SRT。

## 功能

| 功能 | 说明 |
| --- | --- |
| 当前页面提取 | 不需要再复制视频链接，直接处理当前B站视频页 |
| 复用已有登录 | 请求在视频页面中发起，浏览器自动使用已有B站登录状态 |
| 自动字幕 | 可读取平台接口实际返回的AI字幕，也支持人工上传的字幕 |
| 多语言 | 接口提供多个语言时，可选择需要的轨道；工具不会额外翻译 |
| 分P视频 | 按当前链接中的 `p` 参数选择对应分P |
| TXT | 按字幕顺序保存纯文本，适合阅读和做笔记 |
| SRT | 保留字幕时间轴，供支持SRT的剪辑或播放器软件使用 |
| JSON | 保存 `body` 中的 `from`、`to`、`content`，方便进一步处理 |
| 字幕预览 | 显示字幕条数、字符数和前10条文本 |
| 备用捕获 | 保留开发者工具面板，可读取页面已加载的字幕网络响应 |

下载为UTF-8编码。字幕原文不会自动纠错，“漫剧”等词被平台识别错误时，也会按原文导出。字幕时间范围以平台返回的正文为准，可能没有覆盖视频全部声音。

## 安装

这是一个使用 Manifest V3 的 Chrome 扩展。目前以桌面版Chrome为主要使用环境。其他Chromium浏览器可尝试加载，但未单独实测；不支持直接安装到手机Chrome。

1. 从 [Releases](https://github.com/yingy-buxing/bilibili-subtitle-extractor/releases/latest) 下载 `bilibili-subtitle-extractor-v1.1.0.zip` 并解压到一个长期保留的位置。
2. 在Chrome地址栏打开 `chrome://extensions/`。
3. 开启右上角的 **开发者模式**。
4. 点击 **加载已解压的扩展程序**（部分版本称“加载未打包的扩展程序”）。
5. 选择解压后的 **`extension` 文件夹**。这个文件夹里应直接包含 `manifest.json`。
6. 点击Chrome右上角拼图按钮，找到 **B站字幕提取（本地）**。可以点击图钉固定到工具栏。

安装后无需启动本地服务器，不需要Node.js或Python。不要移动或删除已加载的文件夹；更新或移动后的处理方式见[使用指南](docs/USAGE.md)。

## 使用

1. 在Chrome中打开形如 `https://www.bilibili.com/video/BV…/` 的视频页。需要登录才能读取的字幕，请先在B站正常登录。
2. 点击工具栏上的插件图标，再点击 **提取当前视频字幕**。
3. 等待提取完成，期间保持插件窗口打开。
4. 选择字幕语言，必要时修改文件名。
5. 点击 **下载TXT**、**下载SRT** 或 **JSON**。文件保存到Chrome的下载位置；如启用了“下载前询问保存位置”，会出现保存对话框。

如果提示没有字幕，先在播放器 **翻译和字幕** 中开启中文或需要的语言，再尝试提取。若平台仍未通过接口提供字幕，可使用[备用网络捕获方式](docs/USAGE.md#备用方式开发者工具面板)。

## 工作原理

点击插件时，通过Chrome的 `activeTab` 和 `scripting` 能力，在当前B站视频页执行提取函数：

1. 从页面链接读取BV号及分P。
2. 通过B站视频信息接口取得当前分P的 `aid` 和 `cid`。
3. 通过播放器信息接口读取可用字幕轨道。
4. 下载轨道对应的字幕JSON，将字幕文本和时间轴返回插件。
5. 在插件中完成预览与文件生成。

登录相关请求发送到B站API时使用浏览器已有登录状态。插件**不读取Cookie内容**，也不将登录信息返回插件界面；主提取流程向字幕CDN请求时使用 `credentials: omit`。

项目没有自建服务器、统计服务、付费API或远程脚本依赖。详细权限说明见 [PRIVACY.md](docs/PRIVACY.md)。

## 支持范围与限制

- 主流程支持 `www.bilibili.com/video/BV…` 视频页和链接中的分P参数。短链接跳转到正式视频页后再使用。
- 只能导出当前账号通过B站正常访问、且平台实际提供的字幕。工具不会绕过登录、付费或访问限制。
- 不能把画面里的硬字幕直接提取成文本；没有字幕正文时不会自动调用ASR或OCR。
- “播放器能实时显示翻译”不一定意味着接口提供完整的可下载字幕轨道。
- 主流程目前使用B站播放器接口和 `hdslb.com` 字幕CDN。B站更改接口、跨域规则、响应格式或字幕地址后，可能需要更新工具。
- 插件弹窗关闭后，当前操作结果不会长期保存；重新打开后可再次提取。
- 导出只保留字幕原文及时间，不自动整理段落、总结内容或翻译文本。

## 开发与测试

源码没有构建步骤和生产依赖，直接加载 `extension/` 即可使用。测试需要 **Node.js 20或以上**：

```bash
npm test
```

自动检查包括：

- 字幕JSON校验、时间轴合法性、SRT毫秒进位、原文保留。
- HAR明文与Base64正文、多语言轨道、重复请求去重。
- 导出JSON不复制HAR请求地址或请求头。
- 当前分P选择、API请求使用已有登录、字幕CDN不带登录凭据。
- 空字幕、接口错误、网络错误、非法字幕地址和非视频页处理。
- 开发者工具已有请求与实时捕获、去重和清空。

测试使用人工构造的数据，不需要登录B站或提供真实HAR。开发者工具捕获与主提取函数使用模拟浏览器接口测试；自动测试不能替代不同视频、账号和Chrome版本的实机验证。当前一键提取方式已获得Chrome实际使用的可用反馈。

```text
extension/           可直接加载的Chrome插件
  manifest.json      插件信息与权限
  popup.html/js      一键提取与下载界面
  page-extract.js    在B站页面发起字幕请求
  core.js            字幕校验、转换与文件名处理
  devtools.*         备用开发者工具面板入口
  panel.html/app.js  备用捕获与HAR导入界面
tests/               不依赖账号的自动测试
docs/                使用、排查、权限说明
```
